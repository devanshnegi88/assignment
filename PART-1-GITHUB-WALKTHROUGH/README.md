## Live Project


[Live](https://par4good-gamma.vercel.app/)

### Problem It Solves

The Golf Charity Platform is a web application built around golf-related activities and charity participation.

### What I Specifically Built

I worked on the web application and backend functionality, including the parts of the project that I personally implemented such as authentication, database interactions, backend functions, and payment-related functionality.

### Design Decision I Would Change

If I were rebuilding the project today, I would improve the frontend structure by separating application logic into smaller reusable modules and also added a proper backend in place of edge funtions. This would make the project easier to maintain, test, and extend as more functionality is added.

## Repository 2 — Smart Study Assistant

### Repository

[Smart Study Assistant](https://github.com/devanshnegi88/Smart-Study-Assistant)

### Problem It Solves

The Smart Study Assistant is an AI-powered learning application that brings study planning, question answering, notes, quizzes, reminders, and progress tracking into a single application.

### What I Specifically Built

I worked on the backend, database integration, API functionality, and AI-powered features that I personally implemented in the project.

### Design Decision I Would Change

If I were rebuilding the project today, I would separate the AI layer more clearly from the core application logic. This would make it easier to change the AI provider or model without requiring changes throughout the application.
